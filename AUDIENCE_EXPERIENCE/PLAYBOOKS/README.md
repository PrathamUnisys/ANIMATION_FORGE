# Audience Experience Playbooks

**Status:** Draft guidance from the Animation Forge Audience Experience Deep Research report. Not active agent instructions.

| File | Responsibility |
|---|---|
| `SCREENPLAY_ENGINEERING.md` | Long-form story beats, Shorts and screenplay format. |
| `RETENTION_PLAYBOOK.md` | Viewer questions, information progression, pacing heuristics and payoffs. |
| `GENRE_MYSTERY_HORROR_CHECKLISTS.md` | Occult Detective, Dark Folklore, Psychological Horror and Cosmic Horror. |
| `VISUAL_STORYTELLING.md` | Composition, camera, lighting, visual motifs and animation effort. |
| `AUDIO_STORYTELLING.md` | Dialogue, voice, music, silence, ambience and Foley. |
| `PACKAGING_PLAYBOOK.md` | Title/thumbnail promise alignment. |
| `ANALYTICS_PLAYBOOK.md` | Metric interpretation and experiment discipline. |

A playbook becomes active only after source verification, human review, versioning and approved change. Numerical thresholds and timing ranges remain hypotheses unless separately validated.

Use these documents to ask better creative questions, not to force every story into identical beats.
