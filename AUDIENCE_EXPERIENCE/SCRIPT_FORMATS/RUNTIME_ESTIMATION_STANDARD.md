# Screenplay Runtime Estimation Standard

**Status:** DRAFT PROPOSAL. Complements the experiment-specific method in PROJECTS/SCRIPT_LAB_10/DEVELOPMENT/RUNTIME_METHOD.md.

## 1. Runtime evidence levels

Always label the basis of a duration:

1. ROUGH_ESTIMATE: Early planning estimate based on format, beat count, and known constraints.
2. SCRIPT_ESTIMATE: Estimate calculated from screenplay dialogue, action, pauses, silence, and transitions.
3. ANIMATIC_MEASURED: Duration measured from an assembled animatic.
4. FINAL_VIDEO_MEASURED: Duration measured from the final rendered/exported video.
5. NOT_SET: No defensible estimate is available.

Do not describe an estimate as measured playback.

## 2. Script estimate method

Where appropriate, estimate each scene separately:

scene_seconds = dialogue_words / speaking_rate_wpm + action_seconds + silent_beats_seconds + pause_seconds + transition_seconds

Document dialogue word count and assumed speaking rate; action/visual timing assumptions; emotional pauses and reaction holds; transitions and title/credit time where relevant; scene subtotal and episode total; and known uncertainty/excluded material.

The SCRIPT_LAB_10 experiment uses 120–150 words per minute, with 130 WPM as a baseline, plus estimated action, silence, pause, and transition time. Those values are an experiment-specific starting method, not a universal rule for all genres, languages, performances, or animation styles.

## 3. Calibration

When an animatic exists:
- Compare script estimates with measured scene duration.
- Record the difference and likely reason.
- Use project-specific calibration only after enough comparable scenes exist.
- Keep comedy timing, pauses, action, narration, and dialogue delivery distinct where they materially affect duration.

The animatic is the authority for production timing until a final video is available. Final exported runtime is the authority for published duration.

## 4. Format and pacing

Use the target runtime supplied by the approved project/episode brief. The 6–10 minute animated episode template and 30–60 second Short template are format options, not global constraints. Do not add scenes, cuts, twists, or dialogue merely to hit a numerical target.

## 5. Reporting

A runtime report should state target runtime and source; estimate/measured status; method and assumptions; per-scene breakdown when available; total duration and uncertainty; and what has not yet been measured.

Never infer final runtime from word count alone.
