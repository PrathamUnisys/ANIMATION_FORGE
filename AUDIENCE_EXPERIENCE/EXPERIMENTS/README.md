# Audience Experience Experiments

Use this directory to record controlled learning from published work and production tests.

## Principles

- Change a clearly identified variable where practical.
- Compare like-for-like video formats, genres, topics and traffic contexts.
- Use the channel's own historical baseline when relevant.
- Record the observation window and exact metric definitions.
- Do not select a winner from insufficient or incomparable evidence.
- Treat analytics as observations, not direct explanations of viewer motivation.
- Preserve unsuccessful and inconclusive experiments.
- Do not change multiple playbook rules at once without documenting the design.

Use `../TEMPLATES/EXPERIMENT_PLAN_TEMPLATE.md` before testing and `../TEMPLATES/PERFORMANCE_REVIEW_TEMPLATE.md` after collecting results.

This directory does not imply that YouTube Analytics API integration or automated analytics import is implemented.
