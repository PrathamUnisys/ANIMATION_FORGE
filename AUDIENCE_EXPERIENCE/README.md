# Audience Experience

## Purpose

Help Animation Forge plan and review the experience promised to viewers across story development, screenplay, animation, audio, packaging, and post-publication learning. This is a cross-cutting creative layer; it does not replace genre, series format, channel style, story-source governance, rights review, or human approval.

## Status

**DESIGN PACK DRAFT — NOT YET AN ACTIVE RUNTIME FEATURE.**

This directory contains draft standards, a practical screenplay-engineering playbook, playbooks, 30 hook patterns, screenplay templates, JSON contracts, and illustrative examples. These documents do not activate agent behaviour or prove that a database, API, frontend, validator, or production workflow exists. No protected architecture, schema, agent instruction, or runtime behaviour is changed by these documents.

## Evidence and rule discipline

Preserve source, claim, context, limitations, and evidence grade. Distinguish platform documentation, empirical research, practitioner convention, and project hypothesis. Do not infer private retention from public views. Do not turn timing ranges, numerical QA scores, cut frequencies, or title formulas into universal rules. Activate findings only through a reviewed change.

## Intended creative flow

Brief/canon check → dramatic engine → audience promise → character pressure → story spine → rules/clue ledger where relevant → outline and scene cards → hook selection → screenplay → Retention Map from exact screenplay revision → independent creative review → targeted revision → human review.

Packaging, production breakdown, storyboard, camera, audio, publication, and analytics are downstream or parallel workstreams with their own approval and implementation boundaries.

## Architecture boundaries

Genre governs narrative conventions. Series format governs episode relationships. Channel style governs brand/presentation. Audience Experience supplies cross-cutting guidance. Rights remain separate. Creative review is distinct from technical QC and human approval. Existing screenplay schemas and output contracts remain authoritative until approved changes are applied.
