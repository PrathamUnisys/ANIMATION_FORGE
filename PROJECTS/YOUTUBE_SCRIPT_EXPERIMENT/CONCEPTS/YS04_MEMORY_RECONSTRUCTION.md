# YS04 — Why Your Memory Changes When You Recall It

**Category:** Psychology / human behaviour. **Primary title:** `Why Your Memory Changes When You Recall It`. Alternatives: `Your Memory Is Not a Video Recording`; `How a Small Hint Can Change What You Remember`; `Why Confident Memories Can Still Be Wrong`. **Premise:** Memory is not a perfect recording. Recall can be affected by later information and reconstruction, but the science does not mean every memory is false or that a single recall necessarily rewrites it.

**Audience:** General viewers; avoid implying trauma memories are usually false. **Central question:** How can memory preserve useful information while changing details? **Emotional promise:** Recognition and caution, not distrust of all memory. **Why click:** Viewers can test the idea against their own experience. **Why continue:** Move from everyday recall to a classic misinformation experiment, then show limits and practical implications. **Difference:** Separate well-supported findings about suggestion and memory errors from more disputed claims about memory reconsolidation. **Evidence required:** Original Loftus/Palmer study, review literature, APA guidance on limits around recovered traumatic memories. **Thumbnail:** A family photo with one detail blurred and a question mark; text `DID IT HAPPEN?`. **Risks:** Overgeneralizing lab studies; implying people can diagnose true/false memories by confidence; confusing eyewitness memory distortion with trauma-memory debates; promoting distrust of personal memories.

**Hook A:** “You remember the day your class photo was taken. But if someone says there was a red car outside the school, could that detail start to feel familiar later?” **Hook B:** “Your memory can feel like a recording, even though the brain rebuilds details when you remember.” **Selected:** B is clearer and avoids inventing a specific experiment outcome in the hook. The scene can introduce a hypothetical red-car example afterward.

**Research:** Loftus & Palmer, 1974, “Reconstruction of Automobile Destruction”: https://doi.org/10.1016/S0022-5371(74)80011-3 ; critical review of reconsolidation evidence: https://pubmed.ncbi.nlm.nih.gov/29792441/ ; APA, questions on memories of childhood abuse and limits of current evidence: https://www.apa.org/topics/trauma/memories?lang=en .

**Selection:** Selected provisionally for batch 2. Strong everyday relevance; keep the scope narrow and present uncertainty plainly.
