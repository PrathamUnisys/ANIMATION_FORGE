# Script Creation Methodology

This guide is the user-facing summary of the detailed [storytelling methodology](STORYTELLING_METHODOLOGY.md). It documents a proposed method, not an implemented automatic writer.

## The method in brief

Research what can be established. Identify the strongest question or consequence. Choose a story route that fits the evidence. Build an ordered explanation or event chain. Draft for a single narrator and purposeful visuals. Ask a separate reviewer to critique craft. Fact-check claims against sources. Revise without losing version history. Reconcile metadata and ask a human to approve.

## Structure selection

Choose structure based on the topic's natural movement:

- Use event chronology when sequence and decisions matter.
- Use investigation when evidence changes the best explanation.
- Use mechanism-led order when a process itself answers the puzzle.
- Use a concrete case plus broader model when the case demonstrates a bounded principle.
- Use person-led structure only when documented choices and context support it.
- Use a journey/system route when the viewer can follow connected parts.
- Use a thought experiment when it is clearly marked as hypothetical and tests an idea rather than predicting technology.

These are options, not strict genre modes. Combine only when the result stays clear.

## Language and access

Prefer everyday words and short/medium sentences. Explain necessary technical terms on first use. Use an analogy to help comprehension, then state where the analogy stops. Simplify language, not the topic. Review the narration aloud for unclear references, breathless clauses and repeated ideas.

## Claims and visuals

Link factual passages to claim records. Mark reconstructions, composites, diagrams and hypotheticals clearly. A visual metaphor is not proof. Keep causal scope, dates, places, populations and numbers as narrow as the source requires.

## Review and approval

Creative review, factual verification, deterministic QC and human approval are different outputs. A strong review does not prove a story performed well. A QC pass does not approve the script. Final status is decided through the existing human gate.
