# Known Limitations

**Status:** Current limitations of this proposed module as of 2026-11-10.

## Current module status

- Only research/design documentation exists so far; no framework CLI, schema, project templates, prompt executor, automatic research or production exporter has been implemented.
- The proposal has not received a human design acceptance or formal Change Request. It does not update existing Animation Forge protected instructions or schemas.
- No new-topic end-to-end pilot has run through a new framework.
- No separate reviewer agent was available in this session for a new pilot. Existing YS experiment reviews were independently produced and are used as audit evidence.
- No source-checking system can automatically establish truth from links or AI text.
- No YouTube video has been published from the ten-script experiment; there is no retention, CTR, satisfaction or audience comprehension data.
- Runtime has not been measured with recorded narration, animatic or final video.

## Inherent limits of planned workflow

- Source access can be incomplete, paywalled, changed or biased. Claim ledger traceability makes evidence review easier but does not prove evidence quality.
- Historical/scientific interpretation may remain disputed. The workflow must preserve disagreement rather than manufacture certainty.
- Rights, privacy and legal status require separate human/expert review where relevant.
- Editorial judgments vary by reviewer and audience. Findings should be evidence-led but are not objective audience predictions.
- Word count and pace assumptions do not predict final playback; delivery, diagrams, silence, editing and animation timing change runtime.
- A retention map reflects intended progression, not actual audience behavior.
- A small ten-script sample cannot calibrate universal writing rules or scores.

## Shared repository boundaries

- Existing screenwriting review scores and no-score critique guidance are inconsistent; do not select or modify a shared schema without governance review.
- Existing screenplay pipeline stages do not replace research, claim verification or documentary-specific architecture.
- Any protected integration, including `CORE/`, `MODES/`, `SCHEMAS/`, `AGENTS/`, backend runtime or global workflow, requires the repository's approved change process.
