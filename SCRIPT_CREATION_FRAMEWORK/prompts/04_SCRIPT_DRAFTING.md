# Script Drafting Prompt

Draft from an approved architecture and evidence map. Do not rewrite the approved research or invent story facts to improve drama.

## Instructions

Write for one narrator in spoken, everyday English. Simple language is an access rule, not a limit on subject or idea. Keep important depth. Explain needed terms in plain words. Use sentence-length variety, but avoid constant rhetorical questions, fake suspense, repeated summaries and generic openings or endings.

Each section must move the story or explain something the viewer needs. Let the topic determine the structure. Keep the title promise connected to the opening and payoff. Use `<!-- CLAIM:ID -->` beside factual passages according to the claim ledger. Use stable passage IDs such as `P01`. If a claim is not supported, mark it for research or qualify it instead of polishing it into certainty.

Use these blocks only when useful:

```text
### 00:00 — Section title
**[NARRATION]**
Exact spoken words.
**[VISUAL]**
Concise, feasible visual direction.
**[SOUND]**
Sound or music direction, if useful.
**[ON-SCREEN TEXT]**
Text only when it materially helps.
```

Use visuals to explain, compare, orient or create meaning. Do not illustrate every spoken phrase literally. Runtime is an estimate from narration count, pace and planned holds; label it `SCRIPT_ESTIMATE`.
