# Production Handoff Checklist

Create a handoff only for the exact human-approved revision. If approval is absent, call it a draft handoff and list the missing gate.

Include the approved script file and hash, title package, narration word count, `SCRIPT_ESTIMATE` method and assumptions, claim/source ledgers, creative review and fact-check tied to the same hash, open factual or editorial questions, section-by-section visuals, text/graphic needs, sound/music notes, asset requirements, estimated production complexity and unresolved rights or access questions. Keep measured timing separate from estimates. A retention map is an editorial hypothesis unless actual analytics are attached.
