# DEPARTMENT INSTRUCTIONS: POST_PRODUCTION

1. Follow the `GENERATE -> INSPECT -> EVALUATE -> CORRECT -> RESUBMIT -> HUMAN APPROVAL` feedback loop.
2. Never regenerate an entire project when a targeted asset or shot correction is requested.
3. Preserve all approved character, world, and style locks from Creative Memory.
