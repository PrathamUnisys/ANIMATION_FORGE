# Technical Decisions

| Decision | Alternatives considered | Evidence / test | Choice and trade-off | Replacement path |
|---|---|---|---|---|
| Module boundary | Extend current FastAPI/SQLite/React app; modify global schemas; self-contained module | Current ComfyUI adapter is DB-bound simulation; change control protects global schemas/runtime; existing tests have repo-wide write side effects | New `VISUAL_DEVELOPMENT/` package and local project folders. No database migration, existing route, protected schema, or frontend edits. The first review UI is a standalone local tool. Main-app integration requires a later approved CR. | Add authenticated API/routes and React panels only after an approved CR. |
| Project storage | SQLite tables; one mutable JSON; versioned folder artifacts | Need immutable reviewed artifacts and simple backup/inspection | File-backed episode package: immutable inputs and output revisions, JSON manifests, append-only review events. No new database. | A repository can later implement the same storage interface. |
| Approved script gate | Any path supplied by caller; database lookup; signed external manifest | Only `SCR_PROJECT_001_V01` is APPROVED in the current DB; script text is immutable | CLI imports by database script ID using a read-only SQLite connection; rejects missing/non-APPROVED records; stores exact source text, approval state, revision, and SHA-256. Arbitrary files are not silently treated as approved. | Add a trusted approval-manifest adapter after governance/API approval. |
| Script analysis | One large LLM prompt; deterministic parser; parser plus optional provider | Existing screenplay headings and narrator script blocks are structured; local LLM endpoint is known to be unavailable in repository status | Start with deterministic extraction of acts/scenes/speakers/action/narration plus evidence spans and explicit-vs-inferred labels. Add human correction before art generation. Do not invent story facts. | Add an optional structured provider behind an interface; validate every returned quote against the immutable source. |
| IDs | Random IDs; positional IDs; content-derived IDs | Re-running unchanged input should preserve shot references; changed source must be distinguishable | Deterministic IDs for unchanged source and order; every artifact also carries source hash and analysis revision. Changed source creates a new analysis revision and visibly marks old outputs stale. | Human ID mapping tool for screenplay revisions. |
| Art-direction comparison | Independently prompted unrelated images; common scene and workflow | User requires meaningful comparison; style references can only guide, not guarantee exactness | 6–8 structured profiles, same scene, workflow, dimensions and seed; vary style dimensions in a recorded way. Human selects; system never auto-approves. | Add curated profiles per genre after comparing real outputs. |
| Style continuity | Prompt text only; fixed model; optional reference conditioning | IP-Adapter paper shows text/image joint conditioning; ControlNet provides structural conditioning; compatibility is model/workflow-specific | Global style rules are injected into each prompt; configured reference images and workflow bindings are optional. Keep exact workflow/seed/model metadata. Treat prompt consistency as a useful cue, not a guarantee. | Add model-specific IP-Adapter/LoRA/ControlNet workflow templates after live validation. |
| ComfyUI protocol | WebSocket-only; HTTP poll; external queue broker | Official routes expose prompt, queue, history, image view, uploads, and WebSocket progress | Use HTTP queue submission and bounded polling of history/queue. Record each job and preserve raw response/errors. This is easier to test locally and avoids an extra dependency. | Add WebSocket progress transport without changing job records. |
| Workflow configuration | Hard-code nodes/models; API JSON file plus explicit bindings | Existing app adapter hard-codes false installed node/model lists. ComfyUI exposes `/object_info` and model endpoints | Load ComfyUI API-format workflow JSON and declarative node/input bindings; validate against live `/object_info` when available. Ship a minimal baseline template with a user-configured checkpoint name; no model downloads. | Support multiple compatible templates and user-supplied workflow versions. |
| Blocking | AI image only; exact 3D scene generation; explicit 2D layout plus optional image generation | 2D image methods cannot establish calibrated world coordinates; ControlNet can guide spatial appearance but is not a 3D exporter | Produce a deterministic normalized top-down SVG/PNG layout with subjects, props, camera, sightline, and movement arrows. Optionally create a ComfyUI-rendered visual version tied to the same shot. Never claim Blender/Unreal world coordinates. | Add Blender scene/camera export only after a tested measured scale and coordinate convention exist. |
| Review UI | Modify Animation Forge React UI; static HTML; no UI | Existing UI work requires approved integration; images must be inspectable for this module | Standalone local-only review page served by the module; image gallery, side-by-side candidate comparison, status, revisions, and decisions. Writes append-only local review events. | Port to React after formal change approval. |
| Continuity checks | Vision model score; prompt-text inspection; structured checks plus human review | No selected vision model or validated visual-identity metric in current environment | Deterministic checks for IDs, style version, character/prop/location references, scene continuity flags, and manifest metadata; report image identity as NOT_CHECKED unless a human compares it. | Add a vision comparison provider after a benchmark and false-positive review. |
| 3D handoff | Emit exact Unreal/Blender coordinates; carry shot intent | Blender/Unreal tools can use camera transforms when authored, but generated image pixels are not 3D measurements | Export machine-readable shot specs and references, plus current SCENE/SHOT-compatible projections where possible. Coordinate space and units remain unspecified unless explicitly configured and validated. | Add engine-specific exporters as separate adapters with real-file tests. |
